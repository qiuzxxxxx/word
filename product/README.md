# 驻留集｜考研英语学习平台

基于 Django 的考研英语一体化学习软件：词汇背诵、间隔复习、拼写与释义默写（AI 判定）、模拟考试、写作工坊（历年真题 AI 代写/批改）、学习统计与计划，开箱即用。项目命名为「驻留集」（Resident Set），寓意背单词就像操作系统的驻留集常驻内存一样，每天坚持背诵复习。

## 使用

1. 从 [GitHub Releases](https://github.com/qiuzxxxxx/word/releases/latest) 下载最新版 `StudyTool-Setup-版本号.exe`，运行安装程序并按向导选择安装位置；如需免安装版，也可下载 `word.exe`。首次启动约 1–2 分钟自动建库并导入词库与真题
2. AI 功能需先在「设置」页配置模型 API key
3. **关闭窗口即退出程序**
4. 老版本用户可在「设置 → 关于」点「检查更新」，检测到新版本后点一次「立即更新」即全自动完成下载、校验、替换与重启，失败会自动回滚到旧版本

## 最后更新于2026年11月22日（v1.0.0）

本版说明：项目正式更名为「驻留集」；支持 6-12 位密码安全约束与 90 天长效登录保持；支持公告弹窗与历史归档浏览；AI 智能助手全面升级长难句结构拆解、作文批改与移动端抽屉自适应；管理员控台支持用户列表分页控制（10/20/50/100 条）与快速跳页。

若无运行bug将暂停一段时间更新。
